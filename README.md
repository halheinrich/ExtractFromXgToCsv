# ExtractFromXgToCsv

Blazor Web App, run locally: filters the decisions in a folder of eXtreme Gammon (`.xg` / `.xgp`) files and writes them as CSV, Diagram JSON, a PPTX or PDF deck, or `.xgp` position files.

Part of the [backgammon tools umbrella repo](https://github.com/halheinrich/backgammon). What it is, how it works, how to run it and its pitfalls: [INSTRUCTIONS.md](INSTRUCTIONS.md).
